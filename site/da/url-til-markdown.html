URL til Markdown

Indtast en URL og få sidens hovedindhold tilbage som ren Markdown. Artikler, dokumentation og blogindlæg — overskrifter, links, lister, tabeller og kodeblokke bevaret, reklamer og boilerplate væk.

🔒 Intet gemmes. Siden hentes én gang for at konvertere den for dig. Vi gemmer hverken indholdet eller de URL'er du indtaster. Konverteringen kører i din browser.

Hvorfor konvertere sider til Markdown?

  • Fodr dine noter. Gem enhver artikel i Obsidian, Notion eller andre Markdown-værktøjer.
  • Træn og prompt AI-modeller. LLM'er arbejder bedst med ren struktureret tekst, ikke rå HTML.
  • Migrér indhold. Flyt blogindlæg mellem CMS'er uden at miste strukturen.

Ofte stillede spørgsmål

Virker det på alle hjemmesider?

Det virker på de fleste offentlige sider, der kan nås uden login. Sider bag betalingsmur, tunge JavaScript-apps eller sider der blokerer automatisk hentning kan give en fejl.

Gemmes mine data?

Nej. Sidens HTML hentes, konverteres og smides væk med det samme. Intet logges eller gemmes.

Hvordan adskiller det sig fra Clean Copy web-værktøjet?

Web-værktøjet rydder op i tekst, du allerede har. Denne side henter URL'en for dig først, så du springer kopieringen helt over.

Kan jeg gøre det fra kommandolinjen?

Ja — den gratis CLI gør det samme: brew install mahope/clean-copy/clean-copy, derefter clean-copy --url https://eksempel.dk. Se alle installationsmuligheder →

Hvilke elementer konverteres?

Overskrifter h1–h6, fed/kursiv, links, billeder, ordnede og uordnede lister inklusive indlejring, kodeblokke, inline-kode, tabeller (pipe-separeret), afsnit og vandrette linjer. Navigation, sidefod, scripts og styles fjernes.
