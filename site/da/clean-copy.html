Kopiér enhver webside som ren Markdown eller ren tekst.

Clean Copy tager det, du markerer i browseren — eller en hel side, eller en HTML-fil — og giver dig Markdown, der kan sættes direkte ind i Obsidian, en README, en ticket eller en mail. Typografiske anførselstegn, usynlige tegn og layout-støj fjernes undervejs.

Gratis og MIT-licenseret. Din tekst konverteres på din egen maskine — ingen konto, ingen server, ingen tekst sendes nogen steder hen. En Pro-licensnøgle tjekkes online mod mahope.tools.

Se den konvertere en side

Clean Copy er en konverter, så her er den — på vores egen forside. Skriv en adresse, så henter vi siden én gang fra vores server, konverterer den til Markdown her i din browser og viser resultatet. Ingen konto, intet gemt, og konverteringen forlader aldrig denne fane.

Én adresse — en artikel eller en dokumentationsside virker bedst. Vi sætter https:// foran, hvis du lader den være. Hentningen går gennem vores server, og det er også derfor en side bag en login eller en betalingsmur kommer tom tilbage. Konverteringen sker så i denne fane.

Hvad det gør

Markér tekst på en side, højreklik, vælg Copy as Markdown eller Copy as clean text. Eller tryk Ctrl+Shift+C. Den samme converter kører i terminalen:

$ curl -sL https://example.com/artikel | clean-copy
# Artiklens titel

Afsnit bliver til afsnit. Links bliver til [tekst](url), overskrifter beholder
deres niveau, kodeblokke bliver fenced, og tabeller bliver til pipe-tabeller
med den oprindelige kolonnejustering.

$ clean-copy --url https://example.com/docs --text > docs.txt
Markdown der matcher siden
Overskrifter, lister, links, billeder, fed og kursiv, fenced code blocks med sprog-tag, tabeller med justering, nummererede lister der beholder deres startnummer.
Typografisk oprydning
Krøllede anførselstegn bliver lige, hårde mellemrum bliver almindelige, zero-width og andre usynlige tegn fjernes.
Ren tekst
Når du kun vil have ordene: ingen Markdown-syntaks, bare afsnit og linjeskift.
Intet forlader din maskine
Converteren er én lille JavaScript-fil uden runtime-afhængigheder. Extensionen har ingen server; CLI'en åbner kun en netværksforbindelse, hvis du bruger --url. Den ene undtagelse er en Pro-licensnøgle, der valideres online — se spørgsmålet om privatliv nedenfor.

Hvem det er til

Folk, der flytter tekst fra nettet ind i noget andet hver dag: udviklere der skriver docs og tickets, researchere med noter i Obsidian, skribenter der sætter kilder ind i et udkast — og alle, der har sat tekst fra en webside ind i en code editor og fået et krøllet anførselstegn i en string.

Det er én converter leveret i syv former, så du får samme resultat, uanset hvor du er:

  • Chrome / Edge / Brave-extension v1.5.3
  • Firefox-extension v1.5.4, hedder Clean Copy MD
  • Kommandolinje Homebrew eller npm
  • Obsidian-plugin indsæt som Markdown
  • VS Code-extension indsæt som Markdown
  • GitHub Action konvertér URL'er eller filer i CI
  • Webværktøj og bookmarklet uden installation

Installation

Extensions ligger endnu ikke i Chrome Web Store eller på addons.mozilla.org, så de installeres fra en zip-fil. Det tager cirka et minut og kræver ingen developer-konto.

Chrome, Edge, Brave

  1. Download clean-copy-v1.5.3.zip og pak den ud.
  2. Åbn chrome://extensions og slå Developer mode til.
  3. Klik Load unpacked og vælg den udpakkede mappe.

Firefox

  1. Download clean-copy-firefox-v1.5.4.zip og pak den ud.
  2. Åbn about:debugging#/runtime/this-firefox, klik Load Temporary Add-on og vælg manifest.json.
  3. Midlertidige add-ons fjernes, når Firefox lukkes. En signeret udgave til addons.mozilla.org er på vej.

Kommandolinje

brew install mahope/tap/clean-copy      # macOS / Linux
npm install -g github:mahope/clean-copy-cli
npx github:mahope/clean-copy-cli side.html   # kør uden at installere

Læser stdin eller en fil, skriver Markdown til stdout. --url henter en side og beholder selve artiklen, --text giver ren tekst, --copy lægger resultatet på clipboardet. Fuld oversigt: CLI-reference (engelsk).

Obsidian

Tilføj mahope/clean-copy-obsidian via BRAT, eller kopiér main.js, manifest.json og styles.css fra seneste release til .obsidian/plugins/clean-copy-obsidian/. Indsæt derefter med Ctrl+Shift+V. Optagelse i community plugins afventer.

VS Code

Download .vsix-filen fra seneste release og kør code --install-extension clean-copy-1.0.0.vsix, eller brug Install from VSIX i Extensions-panelet. Indsæt HTML som Markdown med Ctrl+Shift+V.

GitHub Action

- uses: mahope/clean-copy-cli@v1
  with:
    url: https://example.com/changelog
    output_file: docs/changelog.md

Tager også file: eller rå html: som input og har fire output-modes: markdown, plain, wikilinks og csv.

Uden installation

Webværktøjet konverterer indsat HTML eller formateret tekst direkte i browserfanen. Bookmarkletten virker i alle browsere. Der er også en URL til Markdown-side og et HTTP-API til scripts, der ikke kan køre Node.

Spørgsmål

Hvorfor ligger extensionen ikke i Chrome Web Store?

Store-listningen kræver en developer-konto og en review-runde, som jeg ikke er færdig med. Load unpacked giver dig præcis samme kode; store-versionen bliver identisk, når den kommer.

Sender den min tekst nogen steder hen?

Den tekst, du konverterer, gør ikke. Extensionen har ingen server, og mens du kopierer, laver den overhovedet ingen netværkskald. CLI'en laver kun en request, når du beder den hente en URL. Konvertereren øverst på denne side er den ene undtagelse på sitet: den sender den adresse, du skriver, til vores server én gang, så den kan hente siden — en browser kan ikke selv hente en side på et andet domæne. HTML'en kommer tilbage og konverteres her i din fane, og vi gemmer hverken adressen eller siden.

Én undtagelse: hvis du aktiverer en Clean Copy Pro-licensnøgle, sendes nøglen og et tilfældigt enheds-id til mahope.tools, så licensen kan valideres. De sider du besøger og den tekst du kopierer sendes aldrig. Uden en Pro-nøgle sendes intet overhovedet.

Hvor god er Markdown-outputtet?

Godt på artikler, dokumentation og de fleste tabeller; kolonnejustering, sprog-tags på kodeblokke og nestede lister bevares. Det er ikke en browser-rendering-engine, så tungt scriptede sider eller indhold, der indsættes efter load, kan komme ufuldstændigt ud. Sæt resultatet ind i webværktøjet, hvis du vil se, hvad converteren gør ved en bestemt side, før du installerer noget.

Chrome advarer om extensions i developer mode.

Den advarsel kommer for alle unpacked extensions. Den forsvinder, når store-listningen findes. Du kan læse hele extensionen igennem — det er nogle få filer uden build-step.

Må jeg bruge converteren i mit eget projekt?

Ja. clean-copy-core.js er ét modul uden afhængigheder under MIT-licens. CLI'en, extensions og plugins importerer det uændret, og en paritetstest sørger for, at de ikke driver fra hinanden.
