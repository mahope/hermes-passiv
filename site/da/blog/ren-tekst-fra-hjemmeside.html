Hvorfor følger formaterne med?

Når du kopierer fra en hjemmeside, tager browseren ikke bare teksten med — den tager hele HTML-repræsentationen: spans med inline-styles, skrifttypedefinitioner, farvekoder, tekstjustering og nogle gange endda usynlige elementer. Word, Outlook og Pages indsætter det hele trofast, og pludselig ligner dit dokument ikke dit eget længere.

🧹 Tre udgange

Rens tekst (behold afsnit og overskrifter), ren Markdown, eller konvertér tabeller. Ét værktøj dækker alle tre.

⚡ Sekunder, ikke genveje-hint

Ingen "indsæt som uformateret tekst"-detour i Word, ingen Notepad-mellemstation. Indsæt, klik, kopier resultatet ud igen.

🔒 Din tekst forbliver lokal

Oprydningen kører i JavaScript i din egen browser. Teksten sendes ikke til nogen server og gemmes ikke.

Sådan gør du (under 10 sekunder)

  1. Kopiér teksten fra hjemmesiden som du plejer (Ctrl/Cmd+C), og åbn det gratis oprydningsværktøj.
  2. Indsæt teksten i feltet (Ctrl/Cmd+V). Alt det grimme format følger gerne med — det er meningen.
  3. Vælg tilstand: ren tekst, Markdown eller tabel-konvertering.
  4. Kopiér resultatet ud og sæt det ind hvor det skal bruges — Word, mail, Obsidian, wherever.

Værktøjet bevarer den struktur der betyder noget — afsnit, overskrifter, lister, links og tabeller — og fjerner alt det der ikke gør: farver, skrifttyper, baggrunde, justeringer og tomme spans.

Tre måder at bruge Clean Copy på

1. Web-værktøjet (denne vej). Ingen installation. Bedst til engangsopgaver og til at prøve det af.

2. Bookmarklet. Træk ét link op i bogmærkelinjen, klik det når du står på en side, og få markeringen kopieret som ren tekst eller Markdown. Virker i alle browsere — hent bookmarklet'et her.

3. Browserudvidelsen. Til daglig brug i Chrome og Firefox: marker, tryk genvejen, og teksten lander ren i udklipsholderen. Se installationsmulighederne →

Ofte stillede spørgsmål

Hvorfor kommer der mærkelige formater med når jeg kopierer fra nettet?

Når du kopierer med Ctrl/Cmd+C, følger HTML'en med: skrifttyper, farver, baggrundsfarver og skjulte styles indsættes i dit dokument. Et oprydningsværktøj stripper alt det og efterlader kun teksten og den grundlæggende struktur.

Kan jeg få teksten som Markdown i stedet?

Ja. Clean Copy kan konvertere markeringen til ren Markdown med overskrifter, lister, links og tabeller — klar til Obsidian, Notion, GitHub eller et CMS.

Er værktøjet gratis?

Ja. Web-værktøjet på /clean-copy-tool kører helt i din browser. Ingen konto, ingen grænser, og din tekst sendes ikke til en server.

Virker det også på tabeller?

Ja. Marker tabellen på siden, vælg tabel-konvertering, og få en pæn pipe-separeret Markdown-tabel du kan sætte direkte ind i docs, README-filer eller Excel via Indsæt-special.
