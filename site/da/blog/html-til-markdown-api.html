HTML til Markdown API:
kald den gratis, lige nu

De fleste konverterings-API'er vil have et kreditkort før de returnerer en eneste overskrift. Dette gør ikke: POST din HTML som JSON og få ren Markdown tilbage — ingen nøgle, ingen konto, intet at installere.

30-sekunders quickstart → Fuld API-reference

Opdateret august 2026 · 4 minutters læsning

Hvorfor en REST-API til det?

Du kan godt konvertere HTML til Markdown i hånden: indsæt det i et converter-faneblad, kopier resultatet tilbage. Det virker én gang. Det virker ikke, når konverteringen skal ligge inde i et script, et build-step, en LLM-pipeline eller et cron-job.

🤖 Fodring af LLM'er

Modeller læser Markdown langt bedre end rå HTML. Strip tags og støj, før sider sendes ind i en prompt — færre tokens, bedre svar.

📚 Indholdspipelines

Hent dokumentation, changelogs eller artikler fra hvor som helst og land dem i dit CMS, din wiki eller dit statiske site som rene Markdown-filer.

🔗 Lim-scripts

Én curl fra bash, ét requests.post() fra Python, ét fetch() fra Node. Kan det tale HTTP, kan det bruge den.

Quickstart på 30 sekunder

Endpointet er POST /api/clean-copy. Send et JSON-objekt med et html-felt; få JSON tilbage med et markdown-felt.

curl

curl -s -X POST https://hermes-passiv.pages.dev/api/clean-copy \
  -H 'Content-Type: application/json' \
  -d '{"html":"<h1>Hej</h1><p>Dette er <b>fedt</b>.</p>"}'
{"ok":true,"markdown":"# Hej\n\nDette er **fedt**.","mode":"markdown","input_chars":42,"output_chars":21}

Python

import requests

r = requests.post(
    "https://hermes-passiv.pages.dev/api/clean-copy",
    json={"html": open("side.html").read()},
    timeout=15,
)
print(r.json()["markdown"])

Node (uden afhængigheder)

const res = await fetch("https://hermes-passiv.pages.dev/api/clean-copy", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ html: "<h2>Dokumentation</h2><p><a href='/'>forside</a></p>" }),
});
const { markdown } = await res.json();

Konvertér en hel URL i stedet for rå HTML

curl -s -X POST https://hermes-passiv.pages.dev/api/clean-copy \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/artikel"}'

API'et henter siden server-side, finder hovedindholdet og returnerer det som Markdown — praktisk når du ikke har HTML'en lokalt endnu.

Ofte stillede spørgsmål

Er den virkelig gratis?

Ja — ingen nøgle, ingen konto, ingen betalingskort. Grænserne er tekniske, ikke kommercielle: 50 KB HTML pr. forespørgsel og en blød grænse på 10 forespørgsler i sekundet.

Hvad hvis min HTML er for stor?

API'et svarer med en fejlbesked, der siger det. Split dokumentet og send delene — overskrifter og links virker på tværs af kald, da konverteringen er stateless.

Gemmer I mit indhold?

Nej. Konverteringen er stateless: din HTML behandles til svaret og opbevares ikke.

Foretrækker du at køre det lokalt?

Samme motor findes offline som Clean Copy CLI, browserudvidelse og npm-bibliotek — se Clean Copy.
