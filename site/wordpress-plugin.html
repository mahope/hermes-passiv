What it does

Most accessibility problems on WordPress sites come from a handful of repeating issues: missing alt text, low-contrast text over theme colours, generic link text like "read more", empty form labels, and missing page language. This plugin scans the page you point it at and lists every one of those issues with its severity and location.

🔍 15 automated checks

Covers images, links, forms, headings, language, viewport, contrast (WCAG 1.4.3 maths), ARIA misuse and more — each mapped to a real WCAG success criterion.

📊 Score & grade

You get a 0–100 score and a letter grade (A–D), plus every finding grouped by severity: errors, warnings and notices — so you know what to fix first.

🔒 Privacy by design

The scan runs on your own server using WordPress's own HTTP client. Nothing is sent to us or any third party. That matters to GDPR-conscious clients — and you can say so in your next pitch.

🌍 Not just for your homepage

Scan any public URL: product pages, landing pages, client sites. The scanner core is platform-independent — use it on Shopify, Webflow or hand-written HTML too.

Installation (2 minutes)

  1. Download the plugin zip.
  2. In your WordPress admin go to Plugins → Add New → Upload Plugin.
  3. Choose the zip, click Install Now, then Activate.
  4. Open Tools → EAA Scanner, paste a URL (your homepage is pre-filled), and hit Scan.

No configuration, no API key, nothing to sign up for. Deactivate and delete removes everything cleanly.
